# Scorsaire — éditeur de partitions

Éditeur de partitions **installable** et utilisable **hors ligne** : notation, tablature, batterie, accords, parties imprimables, synchro et lecteurs.

- Ouvrez l'application : <https://letournedosrossini.github.io/scorsaire-editeur/>
- Lisez le **manuel** (français et anglais, avec captures et glossaire des icônes) : <https://letournedosrossini.github.io/scorsaire-lecteur/manuel/>
- Installez-la depuis le navigateur (« Installer » / « Ajouter à l'écran d'accueil »).
- Vos partitions restent sur votre appareil : rien n'est envoyé nulle part. Un brouillon automatique est gardé dans le navigateur et proposé au prochain lancement si la fermeture a interrompu le travail.
- Une nouvelle version est téléchargée en arrière-plan ; l'application vous propose de la prendre quand vous le décidez.

Le lecteur de recueils (setlists) est une application à part : <https://letournedosrossini.github.io/scorsaire-lecteur/>

Ce dépôt ne contient que l'application construite. Licence GPLv3+ (`LICENSE`) ; polices, glyphes et bibliothèques tierces : voir `LICENSES/`.

# Scorsaire — score editor

An **installable** score editor that also works **offline**: notation, tablature, drums, chords, printable parts, sync and readers.

- Open the app: <https://letournedosrossini.github.io/scorsaire-editeur/>
- Read the **manual** (French and English, with pictures and an icon glossary): <https://letournedosrossini.github.io/scorsaire-lecteur/manuel/>
- Install it from the browser (“Install” / “Add to home screen”).
- Your scores stay on your device: nothing is sent anywhere. An automatic draft is kept in the browser and offered at the next launch if the work was interrupted.
- A new version is downloaded in the background; the app offers it when you decide.

The setlist reader is a separate app: <https://letournedosrossini.github.io/scorsaire-lecteur/>
