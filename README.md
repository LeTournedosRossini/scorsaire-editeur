# Scorsaire — éditeur de partitions

Éditeur de partitions **installable** et utilisable **hors ligne** : notation, tablature, batterie, accords, parties imprimables, synchro et lecteurs.

- Ouvrez l'application : <https://letournedosrossini.github.io/scorsaire-editeur/>
- Installez-la depuis le navigateur (« Installer » / « Ajouter à l'écran d'accueil »).
- Vos partitions restent sur votre appareil : rien n'est envoyé nulle part. Un brouillon automatique est gardé dans le navigateur et proposé au prochain lancement si la fermeture a interrompu le travail.
- Une nouvelle version est téléchargée en arrière-plan ; l'application vous propose de la prendre quand vous le décidez.

Le lecteur de recueils (setlists) est une application à part : <https://letournedosrossini.github.io/scorsaire-lecteur/>
