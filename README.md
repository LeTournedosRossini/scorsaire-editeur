# Scorsaire : l'éditeur

**Scorsaire** est un éditeur de partition qui tient dans un seul fichier : notation, tablature, grille d'accords, rythmique et batterie, avec de vrais sons, des pages à imprimer et des feuilles pour les lecteurs. Il s'ouvre dans le navigateur, sur ordinateur, tablette ou téléphone.

- **Ouvrir l'éditeur** : <https://letournedosrossini.github.io/scorsaire-editeur/>
- **Manuel** (français et anglais, avec captures et glossaire des icônes) : <https://letournedosrossini.github.io/scorsaire-lecteur/manuel/>
- **Le Lecteur** (lire en scène ou en cours, sans rien modifier) : <https://letournedosrossini.github.io/scorsaire-lecteur/>

L'éditeur s'installe comme une application (le menu du navigateur propose « Installer »). Quand une nouvelle version est prête, il propose de se mettre à jour, sans jamais l'imposer. Vos partitions restent sur votre appareil : rien n'est envoyé nulle part.

Ce dépôt ne contient que l'application construite (la page, son manifeste, son service worker et ses icônes), publiée par GitHub Pages. Licence GPLv3+.

# Scorsaire: the editor

**Scorsaire** is a music score editor that fits in a single file: notation, tablature, chord grids, rhythm staves and drums, with real sounds, pages to print and sheets for readers. It opens in the browser, on a computer, a tablet or a phone.

- **Open the editor**: <https://letournedosrossini.github.io/scorsaire-editeur/>
- **Manual** (French and English, with pictures and an icon glossary): <https://letournedosrossini.github.io/scorsaire-lecteur/manuel/>
- **The Reader** (read on stage or in class, without changing anything): <https://letournedosrossini.github.io/scorsaire-lecteur/>

The editor installs like an app (the browser menu offers “Install”). When a new version is ready it offers to update, and never forces it. Your scores stay on your device: nothing is sent anywhere.

This repository holds only the built application (the page, its manifest, its service worker and its icons), served by GitHub Pages. Licence: GPLv3+.
